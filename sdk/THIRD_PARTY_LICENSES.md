# Watcher SDK Third-Party Licenses

This document lists the third-party Python packages the Watcher SDK depends on, with the license under which each is redistributed.

The SDK is source-distributed: each package's full LICENSE text is preserved in your local `site-packages/<pkg>-*.dist-info/LICENSE` after `pip install`.
